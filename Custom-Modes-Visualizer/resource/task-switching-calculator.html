Roo Task Switch Calculator

Optimize your API costs by knowing when to switch tasks

How it Works

The 10x Rule: Switching tasks costs 10x more for one turn (full price vs cached price). This calculator determines if your "history rent" exceeds the "switching penalty."

Key Factors:
  • Heavy System Prompt = Stay longer
  • Bloated History = Switch sooner
  • Many Files Read = Switch sooner
  • High Turn Count = Context pollution risk
